# Codex Change Log

Этот файл предназначен для рабочего журнала изменений, которые Codex вносит в приложение MasterFlow.

## Как вести журнал

После каждого изменения в приложении добавлять новую запись сверху, под разделом `Записи`.

Формат записи:

```md
### YYYY-MM-DD - Краткое название задачи

- Изменено: `path/to/file.ts`, `path/to/other-file.tsx`
- Что сделано: краткое описание фактических изменений.
- Проверка: команды или ручные проверки, которые были выполнены.
- Заметки: риски, ограничения или что нужно проверить позже.
```
